# v2.1.0 Box2d-JNI Release Notes

## API changes

+ Update to Box2D 3.2.0
+ Methods with `Buffer` type parameters were replaced by their address-based equivalents.
+ Updating methods for the new version of Box2D

## New features

+ New `memAddress()` method for obtaining memory addresses
+ New verification methods in the `Checks` class
+ New tests for memory management integrity
+ Adaptation of Box2D-JNI to Box2D 3.2.

## Improvements

+ Some improvements to the `callbacks`
+ Improvements to native code (connections)

## Infrastructure

+ Gradle v9.8.2
+ Android API v9.4.1
+ jreleaser v1.26.0
+ Java 11 compatibility on Android
